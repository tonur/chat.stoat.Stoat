# Stoat (Previously Revolt)

The chat app where you are the main character.

This repo hosts the flatpak wrapper for [Stoat](https://stoat.chat/), available at [Flathub](https://flathub.org/apps/details/chat.stoat.Stoat).

```sh
flatpak install flathub chat.stoat.Stoat
flatpak run chat.stoat.Stoat
```

## Reporting bugs
If you encounter any issues with the Stoat app, please report them to the [Stoat support](https://stoat.chat/support) or on their [GitHub discussions](https://github.com/orgs/stoatchat/discussions)
